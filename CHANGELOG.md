# История изменений (Changelog)

Все значимые изменения проекта документируются в этом файле в соответствии с принципами Keep a Changelog.

## [В разработке / Текущая версия]

## [2.6.3] — 2026-09-05

### Изменено
- Описание сбора данных для карты белых списков в настройках сокращено до одной строки.

## [2.6.2] — 2026-09-05

### Добавлено
- Автоматическое переключение с обычного сервера на LTE при подтверждённом режиме белых списков в мобильной сети и возврат на последний обычный сервер после восстановления полного доступа.
- Скрытый системный профиль маршрутизации `LTE` для LTE-серверов и серверов обхода белых списков: мимо VPN направляются только закреплённые домены и CIDR мобильного белого списка.
- Страна и флаг фактически подключённого сервера в системном VPN-уведомлении.

### Исправлено
- Экран приложения и уведомление теперь используют единый фактический сервер активного туннеля; фоновый выбор по задержке больше не создаёт ложные переключения в интерфейсе.
- Relay-подключения используют общий слой Xray-маршрутизации через локальный аутентифицированный SOCKS5, поэтому системный LTE-профиль одинаково применяется к обеим технологиям обхода.

## [2.6.1] — 2026-09-05

### Изменено
- Отправка обезличенных наблюдений для карты белых списков включена по умолчанию. Ранее сохранённое отключение сохраняется.
- Описание переключателя явно указывает на отправку по умолчанию и возможность отключения; ссылка на карту остаётся рядом.

## [2.6.0] — 2026-09-05

### Добавлено
- Добровольное участие в карте белых списков: отдельный выключенный по умолчанию переключатель и ссылка на карту в настройках.
- Свежие проверки физической сети примерно каждые 15 минут, без GPS, аккаунта и постоянного идентификатора устройства.
- Определение приблизительного региона по исходному IP через локальную базу сервера. Короткоживущие подтверждения хранятся только в памяти и сбрасываются при смене сети.
- Отправка только определённых результатов; неизвестные, просроченные и накопленные офлайн-измерения не выдаются за свежие данные.

## [2.5.0] — 2026-09-01

### Добавлено
- Новый метод подключения для обхода ограничений мобильных сетей («белых списков») с безлимитным трафиком.

### Исправлено
- Исправлено отображение серверов с безлимитным трафиком (значок бесконечности «∞» вместо «0 байт»).
- Исправлено отображение сервера обхода белых списков при отсутствии интернета или сетевых ограничениях.

## [2.4.5] — 2026-08-30

### Исправлено
- Повышена надёжность сетевой защиты и безопасной обработки служебных данных в Android-приложении.

## [2.4.4] — 2026-08-28

### Исправлено
- Direct OTA корректно проверяет единственный текущий сертификат скачанного APK через историю подписи и совместимый fallback для Android 9 и прошивок Android 13, которые не заполняют `apkContentsSigners` архивного пакета.

## [2.4.3] — 2026-08-28

### Изменено
- Размер Direct APK уменьшен более чем вдвое за счёт штатного сжатия нативного VPN-ядра при сохранении всех поддерживаемых ABI и полного функционала.
- Release-проверка теперь блокирует чрезмерно крупный APK, отсутствие любой поддерживаемой архитектуры и несжатые нативные библиотеки.

## [2.4.2] — 2026-08-28

### Исправлено
- Истечение сессии синхронизации больше не отображается как отзыв устройства и не отключает работающий VPN: сохранённый зашифрованный профиль остаётся доступен до фактического окончания подписки.
- Серверные сессии аккаунта больше не наследуют ошибочный однодневный срок внутреннего grant; срок новых grant восстановлен до 30 дней, а действующие сессии безопасно продлены.

## [2.4.1] — 2026-08-27

### Исправлено
- Android 13+ снова создаёт VPN-интерфейс: loopback-диапазоны больше не передаются в системный API, который запрещает такие маршруты; при иных отказах прошивки подключение автоматически повторяется с совместимым набором маршрутов.

## [2.4.0] — 2026-08-27

### Добавлено
- Фоновое определение режима белых списков по физической сети с компактным уведомлением на главном экране и предупреждением перед подключением к LTE-серверу в обычной сети.
- Адаптивная навигация Android TV с управлением с пульта, начальным фокусом, безопасными отступами и ограниченной шириной контента на большом экране.

### Изменено
- Локальные, link-local, carrier-local и multicast IPv4/IPv6-сети всегда обходят VPN-туннель, включая режим Kill Switch.
- Российские серверы доступны только для ручного выбора; автоматический выбор и auto-fallback их больше не используют, а обычные серверы имеют приоритет над LTE.
- LTE-подключение разрешено на физической сети без системного статуса Android «интернет подтверждён», который недоступен при белых списках.

### Исправлено
- Нижняя навигация больше не сжимается системной панелью Android и одинаково располагается при кнопочном и жестовом управлении с учётом увеличенного масштаба текста.

## [2.3.3] — 2026-08-26

### Исправлено
- Пробная подписка обычного VPN теперь загружается по сохранённому идентификатору профиля и сразу появляется в приложении вместе с доступными серверами.
- Временные ошибки проверки подписи запроса больше не удаляют действующую локальную сессию; выход выполняется только при подтверждённом истечении или отсутствии авторизации.

## [2.3.2] — 2026-08-26

### Исправлено
- Временные ошибки проверки подписи запроса, включая рассинхронизацию времени устройства, больше не удаляют действующую локальную сессию.
- Клиент завершает сессию только при подтверждённом сервером истечении или отсутствии авторизации.

## [2.3.1] — 2026-08-26

### Исправлено
- Обычный бесплатный пробный доступ корректно завершает вход после создания профиля в Remnawave.
- Временные ошибки загрузки туннельного профиля после авторизации автоматически повторяются с ограниченной задержкой и больше не показываются пользователю до исчерпания попыток.

## [2.3.0] — 2026-08-26

### Добавлено
- Стартовый выбор бесплатного доступа: обычный VPN без регистрации либо LTE после подтверждения через Telegram-бота.
- Отдельные понятные варианты подтверждения через Telegram-бота и входа через личный кабинет.

### Изменено
- Telegram-бот теперь открывается напрямую в установленном приложении через безопасную нативную ссылку, без перехода через `t.me`.
- Автоматическая OTA-проверка выполняется при возвращении приложения на экран; интервал успешных фоновых проверок сокращён до 6 часов.

### Исправлено
- Сохранена совместимость существующих сессий и гостевого обычного пробного доступа при обновлении.

## [2.2.0] — 2026-08-25

### Добавлено
- Мобильный пробный LTE-доступ на 3 дня с лимитом 1 ГБ после авторизации через Telegram.
- Динамический счётчик использованного LTE-трафика на главном экране с локальным обновлением и регулярной серверной сверкой.

### Изменено
- LTE-подключения используют специальные правила маршрутизации основной DE-ноды.

## [2.1.0] — 2026-08-25

### Добавлено
- Полный Direct purchase flow в приложении: покупка нового доступа, продление, дополнительные устройства и трафик с переходом только на страницу оплаты.
- Трёхдневный пробный обычный VPN без авторизации с серверным одноразовым учётом устройства и восстановлением того же пробника после переустановки.
- Levik Shield, раздельное отображение компонентов Мультиподписки и постоянная кнопка бесплатного Telegram-прокси.
- Живой статус Levik и индикация инцидентов на главном экране.
- Добровольный анонимный радар блокировок с фоновыми проверками только после явного согласия.
- Удалённо обновляемая policy маршрутизации заблокированных и прямых доменов без выпуска новой версии APK.

### Изменено
- Кнопка поддержки теперь открывает `@leviksupportbot`.
- Анонимная телеметрия по умолчанию отключена.

## [2.0.15] — 2026-08-25

  - Новый дизайн логотипа со щитом и скоростной эмблемой.
  - Обновлены адаптивные иконки для всех плотностей экранов, монохромный силуэт для Themed Icons Android 13+ и заставка для Android TV.

## [2.0.14] — 2026-08-24

### Добавлено
- **Гибкая настройка Anti-DPI (TLS-фрагментация)**:
  - Добавлены оптимизированные пресеты фрагментации:
    - *TLS ClientHello (Рекомендуемый)*: дробление только handshake-пакетов ClientHello (`100–200` байт, `10–20` мс) с минимальным влиянием на скорость и пинг.
    - *Микро-фрагментация (Агрессивный)*: разделение пакетов на микрочастицы по `1–5` байт для эффективного пробития жестких DPI/ТСПУ-фильтров.
    - *Умеренная (1–3)*: фрагментация первых трех пакетов соединения блоками по `50–150` байт.
    - *Глубокая (1–5)*: дробление первых пяти пакетов с увеличенной задержкой (`15–30` мс) для переполнения буферов систем анализа трафика.
    - *Пользовательская (Custom)*: ручная настройка пакетов, длины и интервалов задержки с валидацией входных данных.
  - Интерактивный диалог настройки Anti-DPI с быстрым вызовом с главного экрана и экрана профиля.
  - Мгновенное переконфигурирование активного VPN-туннеля на лету без необходимости ручного переподключения.

## [2.0.13] — 2026-08-24

### Исправлено
- OTA-загрузчик разрешает строго ограниченную цепочку HTTPS-redirect через GitHub Releases и `release-assets.githubusercontent.com`, сохраняя проверку размера, SHA-256 и сертификата APK.

## [2.0.12] — 2026-08-24

### Исправлено
- Ручная проверка обновлений больше не блокируется сохранённым сетевым backoff после временного сбоя OTA-сервиса.
- Подпись актуального OTA-feed больше не кешируется как неизменяемый файл и обновляется вместе с `latest.json`.

## [2.0.11] — 2026-08-24

### Безопасность
- Устранены утечки IPv6 и WebRTC: интерфейсу TUN назначен адрес из Global Unicast диапазона (`2600:1900:4000:5255::2/64`), что предотвращает выбор публичного IPv6-адреса физического адаптера по правилу RFC 6724.
- В конфигурацию VPN-интерфейса добавлены IPv6 DNS-серверы для полной изоляции DNS-запросов и предотвращения fallback на DNS физического провайдера.

## [2.0.10] — 2026-08-24

### Исправлено
- Публичный IPv6-трафик теперь блокируется внутри Xray-туннеля, исключая выход через сеть провайдера на устройствах с dual-stack.
- Диалог защиты аккаунта корректно помещает длинный текст и действия на узких экранах; политика конфиденциальности больше не сжимает кнопку отказа.
- Результат запроса геолокации больше не включает автоподключение к недоверенному Wi-Fi без ожидающего пользовательского действия.
- CI больше не публикует debug APK с package ID `com.leviknet.vpn.debug`, который Android устанавливал рядом с production-приложением. Обновления распространяются только подписанным Direct release APK с package ID `com.leviknet.vpn`.

## [2.0.9] — 2026-08-24

### Исправлено
- Устранены утечки IPv6 и DNS: запросы принудительно направляются через IPv4, а весь IPv6-трафик перехватывается туннелем.
- Исправлено возобновление VPN после паузы (устранена взаимная блокировка корутин и восстановлена автоактивация по таймеру).
- Реализован замер задержки (пинг) для серверов Hysteria 2 / UDP через QUIC-датаграммы.
- Исправлена работа кнопки анализа трафика приложений в разделе статистики.
- Восстановлена работа кнопки отключения оптимизации батареи («Работа в фоне») с поддержкой прямого системного диалога.

### Изменено
- Обновлены условия и оформление карточки приглашения друзей в профиле.

## [2.0.8] — 2026-08-24

### Безопасность
- Добавлена строгая проверка контрольных сумм Gradle-зависимостей и инструментов сборки, включая Linux-артефакты, используемые GitHub Actions.
- Канал прямых обновлений защищён подписанным короткоживущим указателем актуальной версии, проверкой соответствия тега и SHA-256 APK, а также защитой от отката на ранее установленную версию.
- Репозиторий подготовлен к безопасному публичному просмотру: из истории удалены посторонние компоненты, усилены политики GitHub Actions и исключён доступ сторонних GitHub Apps.

### Изменено
- Пользовательский GitHub Release содержит только подписанный Direct APK и русское описание; технические доказательства сборки хранятся отдельно в краткоживущем Actions artifact.

## [2.0.7] — 2026-08-24

### Исправлено
- Пользовательский GitHub Release теперь содержит только APK и понятное русское описание; служебные release evidence передаются через краткоживущий внутренний Actions artifact.
- Увеличен timeout защищённой публикации крупного Direct-архива на production-сервер.

## [2.0.6] — 2026-08-24

### Безопасность
- Для private GitHub repository добавлен собственный ECDSA-подписанный release provenance, связывающий repository, commit, tag, workflow run и SHA-256 полного checksum manifest.
- Publisher проверяет provenance, полный набор checksums и update manifest до передачи ограниченного публичного архива на production-сервер.

## [2.0.5] — 2026-08-24

### Исправлено
- Парсер `apksigner` совместим с актуальным форматом Android Build Tools и извлекает последнее поле SHA-256 fingerprint независимо от префикса signer.
- Добавлена отдельная fail-closed проверка, что извлечённый fingerprint содержит ровно 64 шестнадцатеричных символа.

## [2.0.4] — 2026-08-24

### Исправлено
- Закреплён утверждённый production Direct signing certificate для подписанного OTA-канала.
- Fail-closed проверка release evidence теперь сообщает только безопасный публичный fingerprint фактического APK-сертификата при несовпадении, не раскрывая signing secrets.

## [2.0.3] — 2026-08-24

### Исправлено
- Direct OTA переведено на публичный подписанный feed `leviknet.com`, совместимый с private GitHub repository и не требующий токена в приложении.
- Добавлена атомарная публикация неизменяемых Direct-релизов из GitHub Actions через ограниченный forced-command SSH key.
- Усилена проверка release feed, origin/path, semantic version, ECDSA manifest, checksums, attestations и соответствующего исходного кода.

### Безопасность
- GitHub остаётся единственным местом сборки и хранения signing secrets; production web-сервер не получает APK signing key или OTA private key.
- Компрометация release web-hosting не позволяет подделать manifest или APK, проверяемые клиентом по двум независимым ключам доверия.

### Добавлено
- Базовые политики безопасности, правила участия в проекте, лицензии и уведомления сторонних библиотек.
- Архитектурная документация Android-клиента, описание процессов подписи и модели безопасности.
- Автоматические проверки репозитория на отсутствие чувствительных файлов и использование неизменяемых SHA-хешей в GitHub Actions.
- Скрипт безопасной загрузки нативного ядра libXray с проверкой контрольных сумм архива и извлеченного `.aar`.
- Шаблоны GitHub Issues и Pull Requests, конфигурация Dependabot.
- Поддержка двух вариантов сборки: `direct` (прямая загрузка с безопасным OTA) и `play` (для Google Play Store).
- Независимая система авторизации Levik Account без привязки к email/телефону.

### Изменено
- Область видимости репозитория ограничена Android-клиентом Levik VPN.
- Директории сайта и Telegram-моста исключены из Git-отслеживания.
- Конфигурация Dependabot оптимизирована для отслеживания зависимостей Gradle и GitHub Actions.

### Удалено
- Устаревшие серверные сценарии развертывания, не относящиеся к Android-репозиторию.
