# Подпись Android-приложения и нативные зависимости

Цифровая подпись Android-приложения является критическим элементом непрерывности обновлений. Пользователи могут обновлять установленное приложение только в том случае, если новая версия подписана в соответствии с правилами платформы Android.

## Политика подписи

- Зарегистрируйте приложение в **Google Play App Signing** перед открытой публикацией.
- Храните ключ загрузки (upload key) вне Git, архивов исходного кода, Docker-образов и обычных резервных копий рабочих станций.
- Релизная конфигурация Gradle должна прерывать сборку с ошибкой при отсутствии или невалидности keystore/паролей. Использование debug-подписи для release-вариантов строго запрещено.
- В CI keystore декодируется во временный каталог раннера с правами `0600` и удаляется сразу после сборки.
- Запуск релизной подписи защищен GitHub Release Environment с обязательным ручным подтверждением. Ворклоу для pull request никогда не имеют доступа к ключам подписи.
- Релизный артефакт проверяется через `apksigner` с верификацией SHA-256 отпечатка сертификата.

Рекомендуемые имена GitHub Secrets:
`ANDROID_UPLOAD_KEYSTORE_BASE64`, `ANDROID_UPLOAD_STORE_PASSWORD`, `ANDROID_UPLOAD_KEY_ALIAS`, `ANDROID_UPLOAD_KEY_PASSWORD`.

## Аудит установленных сборок

Все исторические APK-файлы версий `1.2.0`–`1.9.0` использовали отпечаток сертификата:
- **SHA-256**: `c1f0cd8239bdb8d2e3802c14d4cbbd7a9cc74a74db78af046985fb1756ed0612`
- **SHA-1**: `62b41e072c7b959441165c729bc72883beab1578`

Этот отпечаток настроен в App Links (`https://leviknet.com/.well-known/assetlinks.json`) и встроенном верификаторе OTA-обновлений для бесшовного обновления установленных сборок.

## Нативное ядро libXray

Сборка использует официальный артефакт libXray `v26.7.28` для Android. CI автоматически скачивает релизный ассет, проверяет SHA-256 архива, извлекает AAR и повторно верифицирует его SHA-256:

- Контрольная сумма архива (SHA-256):
  `28b7dc9d6cc8455fcca5cbd56e387003a7bfb558128651a64899dc3a8ccff666`
- Контрольная сумма извлеченного AAR (SHA-256):
  `4708a361a74f7e955635dbe3661cefb459bdc867423c3b1826a2c5a6ea4ac77d`

Скрипт `scripts/ci/fetch-libxray.sh` обеспечивает автоматическую детерминированную проверку и установку нативного ядра.
