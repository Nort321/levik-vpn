# Процесс релиза Android-приложения Levik VPN

Данный документ регламентирует полный цикл подготовки, валидации, сборки, подписи и публикации релизов Android-приложения Levik VPN.

## Релизные критерии (Release Gates)

1. Релизная версия зафиксирована неизменяемым тегом `vX.Y.Z` в ветке `main`.
2. Политики репозитория и автоматические CI-проверки пройдены успешно без production-секретов.
3. Скрипт `scripts/ci/fetch-libxray.sh` установил зафиксированное нативное ядро и обе проверки SHA-256 завершились успехом.
4. Разрешение зависимостей детерминировано, lock-файлы Gradle актуальны и проверены в строгом режиме (`verifyAllDependencyLocks`).
5. Данные подписи передаются только через защищенную среду GitHub Release Environment; процесс завершается ошибкой при отсутствии или невалидности любого параметра.
6. Отпечаток сертификата подписи точно соответствует эталонному значению.
7. Для собранного артефакта сформирован SBOM, комплект лицензионных уведомлений и архив соответствующего исходного кода (Corresponding Source).
8. Все статические анализаторы (Lint), юнит-тесты и тесты на совместимость пройдены.
9. Публикация в Google Play начинается с закрытого/внутреннего трека тестирования.

## Последовательность сборки и проверки

Используйте JDK 17, Android SDK 36 и Gradle Wrapper:

```bash
# 1. Проверка политик и пинов действий
./scripts/ci/check-repository-policy.sh
./scripts/ci/check-action-pins.sh

# 2. Загрузка нативного ядра
./scripts/ci/fetch-libxray.sh

# 3. Сборка и тестирование Android-проекта
cd levik_vpn_android
./gradlew verifyAllDependencyLocks
./gradlew lintDirectRelease lintPlayRelease
./gradlew assembleDirectRelease bundlePlayRelease
./gradlew testDirectReleaseUnitTest testPlayReleaseUnitTest
./gradlew :app:cyclonedxDirectBom
```

## Подпись релизов

Релизная подпись использует защищенный production-ключ. В GitHub Actions процесс автоматизирован через workflow `.github/workflows/android-release.yml`:
- Запускается вручную только владельцем репозитория.
- Привязан к защищенному окружению `production-release`.
- Формирует AAB для Google Play Store и APK с криптографическим манифестом обновления `update.json.sig` (ECDSA P-256) для прямого распространения.

## Релизные артефакты и аудит

По итогам каждого релиза сохраняются:
- Тег версии и хэш коммита Git
- Контрольные суммы (SHA-256) собранных `.apk` и `.aab`
- Отпечаток сертификата подписи
- Файлы маппинга ProGuard/R8 (`mapping.txt`) и нативные отладочные символы
- Спецификация компонентов SBOM (JSON / XML) и лицензионные уведомления
- Логи успешного прохождения автоматических тестов
